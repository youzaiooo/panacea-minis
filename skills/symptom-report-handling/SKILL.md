# Symptom Report Handling

用户报告**任何症状**（倦怠、疼痛、失眠、腹泻、心悸、头晕…）时，按本 Skill 处理。目标是：不漏记、不错判、
该转诊时不拖延、该观察时不制造恐慌。**本 Skill 只管流程与产出**；医学阈值、红旗清单、分层表**一律写在
健康 Wiki 的 `concepts/` 页**（单一事实来源），skill 里不复制医学数值以免过期。

## 触发条件（含最容易漏的那一种）

- 明说症状：「有点倦怠」「胃不太舒服」「昨晚没睡好」。
- **接在安全告知 / 闲聊之后的一句补充**——上一条回复提到红旗后用户回「乏力不至于，但确实有点倦怠」，
  仍是**一等事件**，不是脚注。**只回话不建档 = 漏记。**
- **用户的用词本身是信息**：区分 fatigue（没精神/倦怠）vs weakness（肌力不足/乏力）vs somnolence（嗜睡）
  vs dyspnea（活动性气促）会改变评估方向 → **原文引用保留在记录里**，不要改写成自己的措辞。

## 固定顺序（先做 1，命中就跳到最后一步）

1. **先扫红旗**：按 Wiki 概念页的红旗清单逐项问自己有无命中。命中 → 直说「尽快就医」，不再展开饮食/生活细节，
   也不给「再观察几天」的替代方案。
2. **绝不诊断、绝不分诊**：措辞用「教育性评估（非诊断）」；给的是**就诊指征**（持续多久 / 进行性加重 /
   新增症状 / 红旗），不是结论。不点名让用户去做某项检查，只写「医生可能按线索考虑…」。
3. **复用本 Wiki 已有客观资料**：先读 `records/labs/`，把与本次主诉相关的**正常值逐项列出**，
   并**写明该检查距今多久**（体检 2 个月 → 只能「降低概率」，固定加一句「不能替代现时复查」）；
   同时查「长期用药」栏——无长期用药就排除了「药物不良反应」这一近期疲劳/不适的常见病因。
4. **用记录算，不用印象**：把近 N 天的摄入 / 体重 / 睡眠汇总成**均值与赤字**（`records/daily/` 可直接取），
   作为「可逆因素」的量化证据；顺手标出该汇总里哪一天是**只报部分餐次**的（剔除后另给一个数）。
5. **盘可逆因素并按可改性排序**（睡眠时长与规律 → 能量摄入是否长期偏低 → 久坐/去适应 → 近期腹泻 →
   咖啡因时间与量 → 情绪/压力）。每条要么有本 Wiki 记录支撑，要么有一篇原始文献（PMID）支撑。
6. **写清边界**：该用户的**主诊断（如轻度血脂升高）本身不解释本症状**——既不把症状归因给它，
   也不因它「只是轻度」而淡忘症状。两头都写出来。
7. **给用户两样东西**：就诊指征 + **1–2 周症状日记**要记的 5 项左右（睡眠时长/入睡时间、症状强度与出现时段、
   是否随活动加重与休息缓解、咖啡因与酒精、当日是否吃够/腹泻）。结尾问 **2–3 个真正会改判读的问题**。

## 产出（少一项即未完成）

- `records/symptoms/YYYY-MM-DD-<slug>.md`：Summary 表（报告时间/用户原话/症状/起病与时程/**严重度按用户报告**/
  伴随症状「未报告」逐项列出/背景/状态=「观察中」）、本 Wiki 客观资料 + 时效、教育性评估、红旗、就诊指征、
  症状日记项、Sources、Provenance。
- 当日 `records/daily/` 头部事件行 + Interpretation 一条；`index.md` 症状节；`log.md` 新条目（置顶）。
- 做过检索 → `raw/sources/<topic>-sources.md` 逐条转录，并写「未采用」及其原因。
- **评估框架可复用就另建 `concepts/` 页**（分层、红旗、判读顺序），症状页与概念页互链；skill 不存数值。

## 取证路径（实测可用）

- 原始研究：Europe PMC REST（`resultType=core`）→ 摘要/全文；`/search` 会间歇 503/超时 → **带退避重试**，
  失败不是「没文献」。
- 框架/教科书层：**Merck Manual Professional**（网页阅读可全文取）。
- 按地区授权的指南摘要服务（如 NICE CKS 在非英国 IP 只返回授权提示页）**不要用搜索摘要顶替**，
  换教科书层来源并在 `raw/sources/` 记录「被挡 + 原因」。
- 不建议自行补剂（无缺铁证据不补铁）——在回复中显式写出这条边界。

## 交付与自检

- 回复结构：**结论（是否红旗/是否需就医）→ 边界 → 已有客观资料 → 可逆因素排序 → 红旗 → 就诊指征 →
  2–3 个问题 → 本轮改动了哪些文件的清单**。
- 自检：红旗清单已过一遍且结论写进记录；体检结论写了「距今多久」；汇总数字是算出来的；用户原话原文保留；
  没有把任何推断写成诊断。
