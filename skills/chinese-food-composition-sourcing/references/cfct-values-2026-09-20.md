# CFCT 已验值：油麦菜 / 萝卜干（咸菜类）/ 带皮鸡肉混合部位（2026-09-20）

一次午餐（咸香鸡饭 + 油麦菜 + 咸萝卜干）查全的三组值。**优先复用本文件，命中即跳过外部查询**；只有本文件没有时才联网重新查。

## 1. 查值手法：全库模糊（省掉分类树猜测）

`categoryOne=0` 时 CFCT 的 AJAX 端点仍会全库模糊匹配，蔬菜与咸菜类都能一击命中，**不必再猜 categoryOne/categoryTwo 编号**：

```sh
curl -s -X POST "https://nlc.chinanutri.cn/fq/FoodInfoQueryAction!queryFoodInfoList.do" \
  -H "X-Requested-With: XMLHttpRequest" \
  -H "Referer: https://nlc.chinanutri.cn/fq/foodlist_0_12_0_0_0_1.htm" \
  --data-urlencode "categoryOne=0" --data-urlencode "categoryTwo=0" \
  --data-urlencode "foodName=油麦菜" --data-urlencode "pageNum=1" \
  --data-urlencode "field=0" --data-urlencode "flag=0"
# 返回 list 行：[id,"",名称,...]，再 web_extract 详情页 foodinfo/<id>.html
```

## 2. 油麦菜 = CFCT id **482**「生菜(牛俐)[油麦菜]」

每 100 g（**生重**，食部 81%）：**69 kJ = 16.5 kcal** / 蛋白 1.4 / 脂肪 0.4 / 灰分 0.4 / **碳水 2.1** / **总膳食纤维未检测** / 钠 80 / 钾 100 / 钙 70 / 磷 31 / 镁 29 / 铁 1.2 / VC **20.0 mg** / 胡萝卜素 360 μg。饱和·单不·多不饱和脂肪酸均「—」（未检测）。

- CFCT 把**油麦菜**归为「生菜（牛俐）」别名 → 即 cos/romaine 型。**纤维补丁：USDA FDC 169247（Lettuce, cos or romaine, raw）2.1 g/100 g，17 kcal**（能量与 CFCT 16.5 高度一致，可互相印证）。
- 餐馆配菜多为白灼/清炒 → **另加油**（3 g 菜籽油 = 27 kcal / 3.0 g 脂肪）。聚合库 交叉条目：`fda4470e` 白灼油麦菜 34 kcal/2.14F、`qingchaoyoumaicai` 清炒 28/1.93、`shuizhuyoumaicai` 水煮 23/1.76、`youmaicai`（生）12/0.4。

## 3. 萝卜干（咸菜类）= CFCT id **1550** —— ⚠️ 钠 4,203 mg/100 g

每 100 g（食部 100%）：**281 kJ = 67.2 kcal** / 蛋白 3.3 / 脂肪 0.2 / **灰分 14.2** / **碳水 14.6** / **总膳食纤维未检测** / **钠 4,203 mg** / 钾 508 / 钙 53 / 磷 65 / 镁 44 / VC 17.0 mg / 铁 3.4 / 锌 1.27。

- **钠换算表（今后直接引用）：20 g → 841 mg；30 g → 1,261 mg；40 g → 1,681 mg**（= WHO <2,000 mg/天 的 42%/63%/84%）。灰分 14.2 g 独立印证高盐（≈10.7 g 盐/100 g）。
- 聚合库 `luobogan` 67 kcal / 3.3P / 0.2F / 14.6C **完全一致**，但 **聚合库不返回钠 → 钠一律以 CFCT 为准**。
- 纤维两库都缺 → 按干基推算 ~2–4 g/100 g，**标低置信、不进结论**。
- **教训：咸菜/腌菜类（萝卜干、榨菜、酸菜、梅干菜）默认按「高钠调味配菜」记账，先查钠再谈热量** —— 一小堆 30 g 就能吃掉全天钠额度的大半，而热量只有 20 kcal，容易被"清淡"误判。
