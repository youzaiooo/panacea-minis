## 奶咖类饮品（dirty / 拿铁）估算模式

- 250ml dirty 咖啡 ≈ 牛奶 200–250ml + 浓缩 30–50ml；浓缩热量可忽略（~2 kcal）
- 最佳估计：按整杯体积计奶量（×2.5 标签值）；plausible range 按奶 200–250ml（±10–20%）
- 无糖浆/炼乳为默认假设，用户未提即不加；提及则需更正
- 已建档奶产品（如小象低脂奶）直接 × 体积倍数，勿重复查库

## USDA FDC 页面坑（实测 2026-08-24）

- **第三方镜像（foodstruct/myfooddata/getfoodfacts/batchbase）显示的 FDC ID 不代表官方页面可加载**：169967（broccoli cooked）、168580（oyster raw）、173424（egg hard-boiled）均报 "Error loading food ID" → 换 历史缓存 / CFCT 兜底，不要反复猜 ID
- DEMO_KEY API（api.nal.usda.gov）不可用（返回 HTML 重定向）→ 直接用 web_extract 抓 `fdc.nal.usda.gov/food-details/{id}/nutrients`
- 页面巨大：Sodium / saturated / Potassium 常落在省略的中间段 → grep 本地保存的页面文件，归档副本至 `raw/sources/usda/`

## 外卖商品详情页截图处理模式

- 商品详情页 = **商家标注配料清单可靠**（可转录为估算基础，优先级低于实物照与包装标签）+ **分量不可靠**（宣传图）
- 实物照片才有分量依据；商品图只提供计数信息（"8个""半个蛋"）与烹饪方式（蒸/煮/炸外观）
- 流程：vision 提取配料表与商品名 → 逐项查历史缓存（先 grep）→ 无缓存再联网查 → 分量按同品类常规分配（medium-low confidence）
- 用户口味描述（如"很干巴"）是酱料/用油量的有效信号：少油少酱 → 酱料按 0 计并在 range 中注明 +20–80 kcal
