# CFCT id 定位与高钙食物取值（中国食物成分表官方查询平台）

平台：`https://nlc.chinanutri.cn/fq/foodinfo/<id>.html`（中国疾控中心营养与健康所 + 中国营养学会）。
数值为**每 100 g 可食部**，取值日 2026-09-21。用前按 SKILL.md「4.5 双源冲突」判据决定是否改用 USDA 为主口径。

## 1. 取数两法

- **名称 → id**：联网搜索 查 `<食物名> nlc.chinanutri.cn foodinfo`，标题里就是 id；
  POST 端点 `FoodInfoQueryAction!queryFoodInfoList.do` 在缺会话/参数时会**静默返回空**（不等于食物不存在）。
- **区间扫描**：id 按品类成段排列，逐 id 取标题+数值并**在 Python 里按关键词过滤后再 print**，
  一次可建一整类的表（见下面的已验区间）。

```python
import urllib.request, re
UA = "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36"
def cfct(fid):
    h = urllib.request.urlopen(urllib.request.Request(
        f"https://nlc.chinanutri.cn/fq/foodinfo/{fid}.html",
        headers={"User-Agent": UA}), timeout=30).read().decode("utf-8", "ignore")
    t = re.sub(r"\s+", " ", re.sub("<[^>]+>", " ", h))
    g = lambda p: (re.search(p, t).group(1) if re.search(p, t) else "?")
    return {"钙": g(r"钙\(Ca\)\s*([\d.]+)"), "蛋白": g(r"蛋白质\(Protein\)\s*([\d.]+)"),
            "能量kJ": g(r"能量[^0-9]{0,80}?([\d.]+)\s*kJ"), "钠": g(r"钠\(Na\)\s*([\d.]+)")}
```

## 4. 这些数值的用法与坑

- **「豆腐」不等于高钙豆腐**：内酯豆腐 **17** vs 北豆腐 **138** mg/100 g（8.1×）；豆腐脑 18；**豆浆 10 = 不是钙源**
  （豆奶 23 同理，除非包装标明钙强化）。用豆腐补钙**必须点名品种**。
- **高草酸菜数值好看但吸收差**：菠菜/苋菜/甜菜叶的钙与草酸结合，人体吸收率极低（Am J Clin Nutr 1988，PMID 3354496）
  → 补钙优先**低草酸**的芥蓝/小白菜类/西兰花/荠菜。
- **虾皮/虾米/虾酱钠极高**（虾皮 5057.7 mg/100 g）→ 每次 5–10 g 当调味，不整勺吃。
- **芝麻酱热量密度高**（624 kcal/100 g）→ 10–15 g 调味（117–176 mg 钙）。
- 单次钙负荷越大吸收比例越低 → 800 mg/天**分 2–3 餐**摄入更有效。
