# 指南可信度评估

用于回答"这份指南能相信吗""这条推荐可靠吗"。不做整体打分，而是**分层结论**：哪些条目可信、
哪些要打折、依据是什么。全程只引用文件本身与被引文献，不凭印象。

## 步骤

1. **定位原文**：拿到官方全文（PDF 或官方期刊页），存入 `raw/sources/guidelines/`。
   基层版/简化版与完整版必须分开对待。
2. **查方法学声明**：是否写明指南制订方法（如 WHO / 中华医学会 / GRADE / IOM）、
   是否有系统检索、核心问题数量、共识方式（Delphi / 会议 / 多数表决）。
3. **抄下证据分级定义**：A/B/C 与 I/IIa/IIb/III 的实际含义。**这是评估的锚点**——
   推荐是 IIa/B 就不该被当成硬指标。
4. **逐条追引文**：对用户关心的那一条，把文献号对应的原文找到，判断引文是否真的支撑推荐。
   - 常见问题：引文支持"替代"却被写成"总量上限"；只有小样本试验 + 观察性研究却标出高等级。
   - 注意中文推荐常把多个主张合并成一条，等级只能覆盖其中一部分。
5. **看 COI 与发布主体**：声明"全部作者无利益冲突"而未附逐人披露，属弱保证；
   记下真正的制订组织（学会/国家中心）。
6. **比对国际最新版本**：ESC/EAS、ACC/AHA、AHA 科学声明、美国膳食指南。
   用 PubMed 检索最新更新（`sort=date`），列出差异点及各自证据等级。
7. **核对时效**：记录该版年份，明确指出已被更晚版本取代的部分。
8. **找"本国特有"条目**：如纳入国际指南不予推荐的药物类别，逐一查其独立 RCT 是否重复出疗效。
9. **给出分层结论 + 对用户的具体落点**，并写回 Wiki（概念页 + `log.md`）。

## 陷阱

- **简化版会丢分级列**：基层版/科普版的表格可能只剩"推荐建议 + 文献号"，
  用 PDF 提取的文本会给不出分级 → 必须回到完整版或英文版核对。
- **翻译歧义**：中文"油脂"(烹调油) 被英译成 "total fat" 会得出完全不同的营养学含义；
  以中文原文为准并显式标注歧义。
- **不同时把指南当整体接受或否决**：同一文件里药物/靶目标可能高度循证，
  饮食条目可能很弱。逐条评估。
- **不要用更新的单篇观察性研究推翻更早的 RCT meta 分析**；新≠更强。
- 证据等级标注真实，不等于结论正确；先看引文层级再看标签。

## 输出形状

```text
结论先行（分层可信/不可信，一句话）
身份与方法学（发布主体、期刊、方法、分级定义、COI）
可信部分
要打折的部分（逐条：推荐等级 + 引文实际层级 + 与国际口径的差异）
对用户的具体落点 + 复诊可问的问题
边界（不构成处方建议）
```

## 参考实例

- 《中国血脂管理指南》完整版2023 / 基层版2024 的评估方法示范（IIa/B 的膳食胆固醇 <300 mg/天 引文仅 2 项小样本试验 + 3 项观察性研究；
  英文版把"油脂 20–25 g"译成 total fat；纳入多廿烷醇而 JAMA 2006 RCT 显示与安慰剂无差异）。
- 评估完成后把结论写成健康 Wiki 的 `concepts/` 页并在 `log.md` 记录。
